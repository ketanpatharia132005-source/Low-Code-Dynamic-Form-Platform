## 🚀 FormCraft – Low-Code Dynamic Form Platform

**FormCraft** is a full-stack, low-code form-building platform designed to simplify the process of creating, managing, sharing, and analyzing dynamic forms without requiring users to write code.

The platform provides an intuitive form-building experience where users can create customized forms, configure different field types, define conditional logic, and collect responses through publicly shareable forms.

It also provides a centralized dashboard for managing forms, monitoring submissions, and analyzing collected data through interactive visualizations.

### ✨ Key Features

- 🧩 **Dynamic Form Builder:** Create and customize forms using different field types and configuration options.
- ⚡ **Conditional Logic:** Define dynamic rules that control form behavior based on user responses.
- 📋 **Form Management:** Create, edit, manage, and duplicate forms.
- 🔗 **Public Form Sharing:** Generate shareable forms that allow users to submit responses without accessing the management dashboard.
- 📊 **Analytics Dashboard:** Monitor form performance, submission statistics, and response distributions through interactive charts.
- 📥 **Response Management:** Browse, view, manage, and delete form submissions.
- 📁 **Data Export:** Export collected form responses in CSV and JSON formats.
- 🔐 **Authentication & Authorization:** Secure user access using JWT-based authentication.
- 🌐 **Multilingual Support:** Support a localized experience for users in different languages.
- 📎 **File Upload Support:** Allow file-based responses through form submissions.

### 🎯 Project Objective

The goal of FormCraft is to make form creation and data collection easier, more flexible, and accessible by providing a scalable platform that combines dynamic form generation, automated workflows, response management, and data analytics in one place.
